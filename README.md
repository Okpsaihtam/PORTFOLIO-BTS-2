# Portfolio · Mathias Celle

Portfolio de Mathias Celle, développeur d'applications full-stack orienté IA (BTS SIO option SLAM, formation Développeur IA à l'EPSI).

Charte « Les Verts » : vert stéphanois, univers du terrain de football, rendu professionnel. Thème clair et sombre automatique.

## Structure

```
index.html                  Accueil : présentation, PPP, compétences, projets, parcours
projets.html                Liste des projets + tableau des compétences du référentiel
projets/*.html              Fiches projet complètes (4)
cv.html                     CV en ligne (+ assets/cv/Mathias-Celle-CV.pdf)
numerique-responsable.html  Objectifs, notions et engagements
veille.html                 Veille technologique
contact.html                Formulaire (Web3Forms) + LinkedIn, GitHub
coulisses.html              Arborescence, rétroplanning, choix de design
assets/css/style.css        Styles (variables de couleur en haut du fichier)
assets/js/main.js           Thème, menu mobile, sommaire, visionneuse, formulaire
assets/img/projets/         Illustrations des projets (SVG)
assets/fonts/               Polices Barlow, Barlow Condensed, JetBrains Mono (auto-hébergées)
```

## Mise à jour

- Remplacer une illustration : déposer une capture (PNG, JPG ou WebP) dans `assets/img/projets/` et changer le nom du fichier dans la fiche concernée.
- Régénérer le CV PDF : ouvrir `cv.html` dans Chrome, Imprimer, « Enregistrer au format PDF », format A4, marges par défaut, graphiques d'arrière-plan cochés.

## Publication

Site statique, compatible GitHub Pages : Settings → Pages → Deploy from branch → `main` / racine.
